# My Portfolio
## Project Name
Personal Portfolio Website
## Description
A personal portfolio website that introduces me as a developer, showcases my skills and projects, and provides ways to contact me.
## Technologies Used
- HTML5
- CSS
- JavaScript
- Git
- GitHub
## Main Sections and Features
- **Home:** Introduction and professional title.
- **About:** Information about me.
- **Skills:** A showcase of my technical skills.
- **Projects:** Project cards featuring descriptions, technologies, and project links.
- **Contact:** Links to GitHub, LinkedIn, and email.
- **Dark Mode:** A button to switch between light and dark themes.
- **Dynamic Footer Year:** Automatically displays the current year.
- **Responsive Design:** Supports desktop and mobile screens.
