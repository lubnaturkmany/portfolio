My Projects

Smart Safety Vest

SmartVest is an IoT-based safety system designed to improve industrial workers safety by monitoring hazardous environmental conditions, including gas leaks, high temperatures, and fire. The system uses sensors and GPS to collect environmental data and track workers locations, sending data to a web-based platform for real-time monitoring and alerts when dangerous conditions are detected.

Technologies Used:

  • Hardware & IoT: ESP32, MQ-2 Gas Sensor, Flame Sensor, DS18B20 Temperature Sensor, NEO-6M GPS Module
  • Backend: Node.js, Express.js.
  • Database: MongoDB.
  • Frontend: React.js, Vite.
  • Communication & Security: HTTP, REST API, JWT Authentication, API Keys.
